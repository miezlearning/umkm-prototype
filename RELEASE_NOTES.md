## 🚀 Pembaruan Aristotle POS v1.1.0 (Production Release)

Selamat datang di rilis **Aristotle POS v1.1.0**! Pembaruan ini menghadirkan lompatan besar dalam arsitektur perangkat keras kasir dan pengalaman pengguna di perangkat Android.

### 🌟 Sorotan Fitur Baru:
* **🔥 Cetak Bluetooth Instan (Zero Dialog):** Cetak struk langsung ke printer thermal Bluetooth (`RPP02N`, VSC, dll.) tanpa RawBT dan tanpa watermark 100%!
* **💰 Laci Kasir Otomatis (*KLAK!*):** Denyut listrik otomatis membuka laci kasir saat transaksi tunai selesai.
* **🖼️ Unggah Foto Logo Toko:** Pemilih file galeri HP kini aktif sepenuhnya untuk kustomisasi logo struk dan profil toko.
* **📷 Pemindai Kamera QRIS:** Scan QRIS dan barcode langsung menggunakan kamera HP/tablet Anda.
* **🏷️ Manajemen Meja & Antrian di HP:** Ubah nama pesanan / meja dengan satu sentuhan lewat tombol cepat (`Meja 1-4`, `Bungkus`, `GoFood`, `GrabFood`).
* **🔄 Alur Kasir Cerdas:** Nama pesanan otomatis kembali bersih ke `Pesanan #1` setelah transaksi selesai diproses.
* **🌐 Over-The-Air (OTA) Cloud Sync:** Aplikasi selalu memuat pembaruan fitur web terbaru secara otomatis tanpa perlu menginstal ulang file APK.

### 📦 Unduh File APK:
Unduh file **`Aristotle-POS.apk`** di bawah ini untuk dipasang di smartphone atau tablet kasir Anda.
